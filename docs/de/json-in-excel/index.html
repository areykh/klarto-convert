JSON in Excel umwandeln (XLSX)

Wählen Sie eine JSON-Datei aus oder fügen Sie JSON ein. Sie erhalten eine .xlsx-Datei mit Kopfzeile. JSON-Zahlen, boolesche Werte und Zeichenketten behalten in Excel ihren Typ.

Ihre Datei bleibt auf Ihrem Gerät: Die Umwandlung läuft in Ihrem Browser, und nichts wird hochgeladen.

    So gehen Sie vor

    1. Wählen Sie eine JSON- oder JSON-Lines-Datei aus, ziehen Sie sie auf das Feld oder fügen Sie JSON ein. Klicken Sie dann auf „Umwandeln“.
    2. Prüfen Sie „Zeilen aus“, und wählen Sie ein anderes Array, falls das Tool das falsche gewählt hat.
    3. Entscheiden Sie, ob ISO-Datumszeichenketten zu Excel-Datumswerten werden sollen.
    4. Prüfen Sie die Vorschau und laden Sie die .xlsx-Datei herunter.

    So funktioniert die Umwandlung

    Die Array-Regel: verschachtelte Daten in Spalten

    • Verschachtelte Objekte ergeben Spaltennamen mit Punkten: customer.name, customer.address.city.
    • Arrays ergeben nummerierte Spalten, beginnend bei 0: tags.0, tags.1. Arrays von Objekten kombinieren beides: items.0.sku, items.0.qty, items.1.sku.
    • Ein leeres Objekt oder Array ergibt eine leere Zelle unter seinem eigenen Spaltennamen.
    • Die Spalten erscheinen in der Reihenfolge, in der sie zuerst vorkommen. Fehlt einer Zeile ein Wert, bleibt die Zelle leer.
    • Die Zeilen kommen aus einem Array auf oberster Ebene, falls es eines gibt. Sonst wird das größte Array von Objekten verwendet, zum Beispiel orders; unter „Zeilen aus“ können Sie ein anderes wählen. Ohne ein solches Array ist das ganze Dokument eine Zeile.

    So wird die Excel-Datei geschrieben

    • JSON-Typen bleiben erhalten: Zahlen werden zu Zahlenzellen, true und false zu Wahrheitswerten, Zeichenketten zu Textzellen; "01067" bleibt also Text.
    • Ist „ISO-Datumswerte als Excel-Datum“ eingeschaltet, werden Zeichenketten wie 2026-11-20 oder 2026-11-20T14:30:00 zu Datumszellen. Zeichenketten mit Zeitzone (Z oder +02:00) bleiben Text, weil Excel-Zellen keine Zeitzone kennen.
    • Die erste Zeile ist die Kopfzeile: Sie erhält einen AutoFilter, und die Spaltenbreiten richten sich nach den ersten 200 Zeilen.
    • Ein Tabellenblatt fasst höchstens 1.048.576 Zeilen und 16.384 Spalten, eine Zelle höchstens 32.767 Zeichen. Größere Daten werden abgelehnt, längerer Text wird mit einer Warnung gekürzt.

    Fragen und Antworten

    Bleiben Zahlen in Excel Zahlen?

    Ja. JSON-Zahlen werden zu Zahlenzellen, true und false zu Wahrheitswerten und Zeichenketten zu Textzellen. So behält "01067" seine führende Null.

    Wie werden Datumswerte behandelt?

    Ist „ISO-Datumswerte als Excel-Datum“ eingeschaltet, werden Zeichenketten wie 2026-11-20 oder 2026-11-20T14:30:00 zu Datumszellen. Zeichenketten mit Zeitzone, etwa 2026-11-20T14:30:00Z, bleiben Text, weil Excel-Zellen keine Zeitzone kennen.

    Wie werden verschachtelte Objekte und Arrays angeordnet?

    Nach der Array-Regel: Verschachtelte Objekte ergeben Spaltennamen mit Punkten (customer.city), Arrays nummerierte Spalten (items.0.sku, items.1.sku). Jedes Array-Element erhält eigene Spalten, daher bleibt die Zahl der Zeilen gleich der Zahl der Datensätze.

    Ist die Excel-Datei formatiert?

    Nur wenig: Die Kopfzeile erhält einen AutoFilter, und die Spaltenbreiten richten sich nach den ersten 200 Zeilen. Schriftarten, Farben und fixierte Bereiche werden nicht festgelegt.
