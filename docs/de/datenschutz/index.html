Datenschutz

Ihre Dateien

Dateien, die Sie auswählen, und Text, den Sie einfügen, werden nur in Ihrem Browser auf Ihrem Gerät verarbeitet. Sie werden nicht hochgeladen, nicht gespeichert und weder an uns noch an Dritte gesendet. Die einzigen Netzwerkanfragen der Seiten gelten den eigenen Dateien der Website (Seiten, Stylesheets und Skripte). Ihre Content Security Policy blockiert Anfragen, über die Skripte Daten senden könnten (connect-src 'none'), und das gilt auch für den Hintergrund-Worker, der die Umwandlung ausführt.

Keine Cookies, kein Tracking

Diese Website setzt keine Cookies, nutzt keinen lokalen Speicher (Local Storage) und enthält keinen Code für Webanalyse, Werbung oder soziale Medien. Alle Dateien der Website, auch die Bibliothek SheetJS, werden von dieser Website selbst ausgeliefert, nicht von Servern Dritter.

Hosting

Die Website wird bei GitHub Pages gehostet, einem Dienst der GitHub, Inc. Laut der Dokumentation von GitHub wird die IP-Adresse jedes Besuchers einer GitHub-Pages-Website aus Sicherheitsgründen protokolliert und gespeichert. Wir haben keinen Zugriff auf diese Protokolle. Einzelheiten stehen in der Datenschutzerklärung von GitHub.

Wer diese Website betreibt
