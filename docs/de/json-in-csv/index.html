JSON in CSV umwandeln

Wählen Sie eine JSON-Datei aus oder fügen Sie JSON ein. Sie erhalten eine CSV-Datei. Verschachtelte Objekte und Arrays werden nach einer festen Regel abgeflacht, die unten beschrieben ist.

Ihre Datei bleibt auf Ihrem Gerät: Die Umwandlung läuft in Ihrem Browser, und nichts wird hochgeladen.

    So gehen Sie vor

    1. Wählen Sie eine JSON- oder JSON-Lines-Datei aus, ziehen Sie sie auf das Feld oder fügen Sie JSON ein. Klicken Sie dann auf „Umwandeln“.
    2. Prüfen Sie „Zeilen aus“: Ein Array auf oberster Ebene wird direkt verwendet, sonst das größte Array von Objekten. Wählen Sie bei Bedarf ein anderes.
    3. Wählen Sie Trennzeichen und Dezimaltrennzeichen so, wie Ihr Tabellenkalkulationsprogramm sie erwartet. Voreingestellt sind Semikolon und Dezimalkomma, passend zu Excel mit deutschen Regionseinstellungen. Lassen Sie „UTF-8-BOM für Excel“ eingeschaltet, wenn Sie die Datei in Excel öffnen.
    4. Laden Sie die .csv-Datei herunter oder kopieren Sie das Ergebnis.

    So funktioniert die Umwandlung

    Die Array-Regel: verschachtelte Daten in Spalten

    • Verschachtelte Objekte ergeben Spaltennamen mit Punkten: customer.name, customer.address.city.
    • Arrays ergeben nummerierte Spalten, beginnend bei 0: tags.0, tags.1. Arrays von Objekten kombinieren beides: items.0.sku, items.0.qty, items.1.sku.
    • Ein leeres Objekt oder Array ergibt eine leere Zelle unter seinem eigenen Spaltennamen.
    • Die Spalten erscheinen in der Reihenfolge, in der sie zuerst vorkommen. Fehlt einer Zeile ein Wert, bleibt die Zelle leer.
    • Die Zeilen kommen aus einem Array auf oberster Ebene, falls es eines gibt. Sonst wird das größte Array von Objekten verwendet, zum Beispiel orders; unter „Zeilen aus“ können Sie ein anderes wählen. Ohne ein solches Array ist das ganze Dokument eine Zeile.

    So wird CSV geschrieben

    • Felder, die das Trennzeichen, ein doppeltes Anführungszeichen oder einen Zeilenumbruch enthalten, werden in doppelte Anführungszeichen gesetzt; Anführungszeichen darin werden verdoppelt. Zeilen enden mit CRLF.
    • Mit Dezimalkomma werden JSON-Zahlen als 1,5 geschrieben. Textwerte werden nie verändert.
    • Die UTF-8-Bytereihenfolge-Markierung (BOM, drei Bytes am Anfang) sorgt dafür, dass Excel die Datei als UTF-8 öffnet. So werden Zeichen wie ü, é oder ж richtig angezeigt.

    Fragen und Antworten

    Wie werden verschachtelte Objekte und Arrays abgeflacht?

    Verschachtelte Objekte ergeben Spaltennamen mit Punkten, etwa customer.city. Arrays ergeben nummerierte Spalten, beginnend bei 0: tags.0, tags.1, und bei Arrays von Objekten items.0.sku, items.1.sku. Ein leeres Objekt oder Array ergibt eine leere Zelle. Die Spalten erscheinen in der Reihenfolge, in der sie zuerst vorkommen.

    Welches Trennzeichen sollte ich für Excel wählen?

    Excel unter Windows öffnet CSV-Dateien mit dem Listentrennzeichen aus den Regionseinstellungen. In den USA und in Großbritannien ist das ein Komma; in Deutschland, Frankreich, Spanien und vielen anderen Ländern ist es ein Semikolon, mit Komma als Dezimaltrennzeichen. Wählen Sie Trennzeichen und Dezimaltrennzeichen passend dazu. Auf dieser Seite sind Semikolon und Dezimalkomma voreingestellt.

    Warum sehen Umlaute oder Akzente in Excel falsch aus?

    Excel unter Windows öffnet eine CSV-Datei ohne Bytereihenfolge-Markierung (BOM) in der älteren Standardkodierung des Systems statt in UTF-8. Lassen Sie die Option „UTF-8-BOM für Excel“ eingeschaltet: Sie fügt am Anfang drei Bytes ein, die Excel mitteilen, dass die Datei UTF-8 ist.

    Kann ich JSON Lines umwandeln?

    Ja. Eine Datei mit einem JSON-Wert pro Zeile (JSON Lines, NDJSON) wird als Liste gelesen, und jede Zeile wird zu einer Datenzeile.

    Sind sehr große Zahlen sicher?

    Browser lesen JSON-Zahlen als 64-Bit-Gleitkommazahlen. Ganze Zahlen über 9.007.199.254.740.991 werden daher schon vor der Umwandlung gerundet. Das Tool warnt, wenn es eine solche Zahl findet. Speichern Sie solche IDs im JSON als Zeichenketten in Anführungszeichen.
