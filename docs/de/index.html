XML-, JSON-, CSV- und Excel-Dateien im Browser umwandeln

Zehn kleine Tools für alltägliche Datendateien. Jedes läuft vollständig in Ihrem Browser, erklärt seine Umwandlungsregeln und zeigt genaue Fehlermeldungen.

Tools

  • XML in JSONMit Attributen, Namensräumen und CDATA.
  • JSON in XML@-Schlüssel werden Attribute, Arrays wiederholte Elemente.
  • XML in ExcelEine Zeile pro Datensatz, Zahlen und Datumswerte als echte Zellen.
  • Excel in XMLJedes Tabellenblatt in XML, Überschriften als Elementnamen.
  • JSON in CSVVerschachtelte Daten in Spalten mit Punkt, bereit für Excel.
  • CSV in JSONTrennzeichen automatisch, Felder in Anführungszeichen, europäisches CSV.
  • JSON in ExcelJSON-Typen bleiben erhalten, ISO-Datumswerte als Datumszellen.
  • Excel in JSONZeilen als Objekte, Datumswerte in ISO 8601.
  • CSV in ExcelFührende Nullen und lange Zahlen bleiben unverändert.
  • XML-ValidatorPrüft die Wohlgeformtheit, zeigt Zeile und Spalte.

Was diese Tools anders machen

  • Ihre Dateien werden nicht hochgeladen. Die Umwandlung läuft in Ihrem Browser: Die Seiten laden nur ihre eigenen Dateien von dieser Website und senden Ihre Daten nirgendwohin. Das können Sie im Tab „Netzwerk“ der Entwicklertools Ihres Browsers prüfen.
  • Die Regeln stehen auf jeder Seite: wie Attribute, Arrays, verschachtelte Objekte, Zahlen und Datumswerte umgewandelt werden. So wissen Sie, was Sie erwartet.
  • Fehlermeldungen nennen Zeile und Spalte und sagen, wie Sie das Problem beheben.

Fragen und Antworten

Ist das kostenlos?

Ja. Die Tools sind kostenlos und brauchen kein Konto.

Welche Browser funktionieren?

Aktuelle Versionen von Browsern, die JavaScript-Module in Web Workers unterstützen. Wir testen die Seiten in Google Chrome.

Werden meine Dateien irgendwo gespeichert?

Nein. Dateien werden in den Arbeitsspeicher Ihres Browser-Tabs gelesen und sind weg, sobald Sie die Seite schließen oder neu laden. Es gibt keine Cookies und keine Webanalyse.
