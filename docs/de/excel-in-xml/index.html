Excel in XML umwandeln

Wählen Sie eine Arbeitsmappe aus, um eines ihrer Tabellenblätter in XML umzuwandeln: ein Element pro Zeile, ein Kindelement pro Spalte, Datumswerte in ISO 8601.

Ihre Datei bleibt auf Ihrem Gerät: Die Umwandlung läuft in Ihrem Browser, und nichts wird hochgeladen.

    So gehen Sie vor

    1. Wählen Sie eine .xlsx-, .xlsm-, .xlsb-, .xls- oder .ods-Datei aus, oder ziehen Sie sie auf das Feld.
    2. Hat die Arbeitsmappe mehrere Tabellenblätter, wählen Sie eines in der Liste „Tabellenblatt“.
    3. Legen Sie die Namen des Wurzel- und des Zeilenelements fest. Schalten Sie „Spaltennamen mit Punkt verschachteln“ ein, wenn Sie verschachteltes XML möchten.
    4. Laden Sie die .xml-Datei herunter oder kopieren Sie das Ergebnis.

    So funktioniert die Umwandlung

    So wird die Arbeitsmappe gelesen

    • Formate: .xlsx, .xlsm, .xlsb, .xls (Excel 97–2003) und .ods (LibreOffice, OpenOffice). Ein Tabellenblatt pro Umwandlung; Sie wählen es nach dem Laden aus.
    • Zahlenzellen bleiben Zahlen, Textzellen bleiben Text: Eine als Text gespeicherte Postleitzahl wie 01067 behält ihre führende Null. WAHR und FALSCH werden zu booleschen Werten, Fehlerzellen zu ihrem Code wie #DIV/0!, leere Zellen zu null (in XML zu einem leeren Element).
    • Als Datum formatierte Zellen werden zu ISO-8601-Text: 2026-11-20, 2026-11-20T14:30:00 oder 14:30:00 für eine Uhrzeit; eine Zeitzone wird nicht hinzugefügt. Arbeitsmappen mit dem 1904-Datumssystem werden korrekt verarbeitet.
    • Bei Formeln wird das in der Datei gespeicherte Ergebnis verwendet; nichts wird neu berechnet. Eine verbundene Zelle hat ihren Wert nur in der Zelle oben links.
    • Leere Überschriftenzellen heißen column_N, doppelte Überschriften erhalten _2, _3.

    Vom Tabellenblatt zu XML

    • Jede Zeile unter der Kopfzeile wird zu einem Element (standardmäßig <row>) innerhalb des Wurzelelements (standardmäßig <rows>); jede Spalte wird zu einem Kindelement, das nach ihrer Überschrift benannt ist.
    • Überschriften, die keine gültigen XML-Namen sind, werden angepasst: Leerzeichen und andere ungültige Zeichen werden zu „_“. Eine Überschrift, die mit „@“ beginnt, wird zu einem Attribut.
    • Ist „Spaltennamen mit Punkt verschachteln“ eingeschaltet, wird address.city zu <address><city>…</city></address>.

    Fragen und Antworten

    Welche Dateien kann ich verwenden?

    Excel-Arbeitsmappen (.xlsx, .xlsm, .xlsb), alte Dateien aus Excel 97–2003 (.xls) und OpenDocument-Tabellen (.ods). Kennwortgeschützte Dateien lassen sich nicht lesen: Entfernen Sie zuerst das Kennwort in Excel. Für CSV-Dateien verwenden Sie „CSV in JSON“ und danach „JSON in XML“.

    Wie sieht das XML aus?

    Jede Zeile unter der Kopfzeile wird zu einem <row>-Element innerhalb von <rows>, und jede Zelle wird zu einem Kindelement, das nach der Überschrift ihrer Spalte benannt ist. Beide Elemente können Sie umbenennen. Überschriften, die mit „@“ beginnen, werden zu Attributen, und leere Zellen werden zu leeren Elementen wie <note/>.

    Wie werden Datumswerte und Formeln umgewandelt?

    Als Datum formatierte Zellen werden zu ISO-8601-Text, zum Beispiel 2026-11-20 oder 2026-11-20T14:30:00. Bei Formeln wird der in der Datei gespeicherte Wert verwendet; Formeln werden nicht neu berechnet.

    Kann ich verschachteltes XML erzeugen?

    Ja. Schalten Sie „Spaltennamen mit Punkt verschachteln“ ein: Eine Spalte namens address.city wird zu <address><city>…</city></address>, und nummerierte Spalten wie phone.0 und phone.1 werden zu wiederholten <phone>-Elementen.
