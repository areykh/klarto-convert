    How to use it

    1. Choose an XML file, drop it on the box, or paste XML into the text field and press Convert.
    2. Check the options: whether repeated elements are arrays everywhere, which elements should always be arrays, and the indentation.
    3. Look at the preview, then download the .json file or copy the result.
    4. If the XML has an error, the message shows the line and the column. Fix it and convert again.

    How the conversion works

    XML and JSON mapping

    • Each element becomes a key with the element's name. Namespace prefixes stay part of the name: soap:Body.
    • Attributes become keys with an “@” in front: id="7" becomes "@id": "7". Namespace declarations are kept the same way, as "@xmlns:soap".
    • An element with only text becomes that text. If it also has attributes or child elements, its text goes under "#text": <price currency="EUR">12.50</price> becomes {"price": {"@currency": "EUR", "#text": "12.50"}}.
    • Elements that repeat under the same parent become an array, in document order. Interleaved names are grouped, so the order between different names is not kept.
    • CDATA sections become ordinary text. Comments, processing instructions and the DOCTYPE are dropped. Entities defined only in an external DTD, such as &nbsp; in XHTML, are kept as written, with a note.
    • An empty element such as <note/> becomes "". Whitespace between elements is dropped and text is trimmed, except inside xml:space="preserve".
    • All values stay strings, because XML has no data types: "00123" keeps its leading zeros.

    Questions and answers

    How are attributes and text stored in the JSON?

    Each attribute becomes a key with “@” in front of its name, so id="7" becomes "@id": "7". An element with only text becomes that text. If the element also has attributes or child elements, the text is stored under "#text".

    Why are all numbers in quotes?

    XML has no data types, so every value is converted as a string. Turning "00123" or "1e5" into numbers would change the data. Convert the types in your own code, where you know which fields are numbers.

    When does an element become an array?

    When it appears more than once under the same parent. With “Repeated elements as arrays everywhere” on (the default), an element that repeats anywhere becomes an array at the same path in every record, so all records have the same shape. For elements that never repeat in this file, enter their names under “Always arrays”.

    What happens to namespaces, comments and CDATA?

    Prefixes stay in the names, such as "soap:Body", and namespace declarations are kept as "@xmlns" keys, so JSON to XML gives back the same namespaces. CDATA sections become ordinary text. Comments and processing instructions are dropped.
