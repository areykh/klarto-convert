Convertir Excel en XML

Choisissez un classeur pour transformer l'une de ses feuilles en XML : un élément par ligne, un élément enfant par colonne, avec les dates en ISO 8601.

Votre fichier reste sur votre appareil : la conversion se fait dans votre navigateur et rien n'est envoyé.

    Mode d'emploi

    1. Choisissez un fichier .xlsx, .xlsm, .xlsb, .xls ou .ods, ou déposez-le dans la zone.
    2. Si le classeur contient plusieurs feuilles, choisissez-en une dans la liste « Feuille ».
    3. Définissez les noms de l'élément racine et de l'élément de ligne, et activez « Imbriquer les en-têtes à points » si vous voulez du XML imbriqué.
    4. Téléchargez le fichier .xml ou copiez le résultat.

    Fonctionnement de la conversion

    Lecture du classeur

    • Formats : .xlsx, .xlsm, .xlsb, .xls (Excel 97–2003) et .ods (LibreOffice, OpenOffice). Une feuille par conversion ; choisissez-la après le chargement.
    • Les cellules numériques restent des nombres, les cellules texte restent du texte : un code postal stocké en texte, comme 01067, garde son zéro initial. VRAI et FAUX deviennent des booléens, les cellules d'erreur leur code, comme #DIV/0!, et les cellules vides null (en XML, un élément vide).
    • Les cellules au format date deviennent du texte ISO 8601 : 2026-11-20, 2026-11-20T14:30:00, ou 14:30:00 pour une heure ; aucun fuseau horaire n'est ajouté. Les classeurs qui utilisent le calendrier depuis 1904 sont pris en charge.
    • Pour les formules, le résultat enregistré dans le fichier est utilisé ; rien n'est recalculé. Une cellule fusionnée n'a sa valeur que dans sa cellule en haut à gauche.
    • Les cellules d'en-tête vides sont nommées column_N, les doublons reçoivent _2, _3.

    De la feuille vers le XML

    • Chaque ligne sous l'en-tête devient un élément (par défaut <row>) dans l'élément racine (par défaut <rows>) ; chaque colonne devient un élément enfant nommé d'après son en-tête.
    • Les noms d'en-tête qui ne sont pas des noms XML valides sont adaptés : les espaces et les autres caractères invalides deviennent « _ ». Un en-tête qui commence par « @ » devient un attribut.
    • Avec « Imbriquer les en-têtes à points » activé, address.city devient <address><city>…</city></address>.

    Questions et réponses

    Quels fichiers puis-je utiliser ?

    Les classeurs Excel (.xlsx, .xlsm, .xlsb), les anciens fichiers Excel 97–2003 (.xls) et les feuilles de calcul OpenDocument (.ods). Les fichiers protégés par un mot de passe ne peuvent pas être lus : supprimez d'abord le mot de passe dans Excel. Pour les fichiers CSV, utilisez CSV en JSON, puis JSON en XML.

    À quoi ressemble le XML ?

    Chaque ligne sous l'en-tête devient un élément <row> dans <rows>, et chaque cellule devient un élément enfant nommé d'après l'en-tête de sa colonne. Vous pouvez renommer ces deux éléments. Les en-têtes qui commencent par « @ » deviennent des attributs, et les cellules vides deviennent des éléments vides comme <note/>.

    Comment les dates et les formules sont-elles converties ?

    Les cellules au format date deviennent du texte ISO 8601, par exemple 2026-11-20 ou 2026-11-20T14:30:00. Pour les formules, la valeur enregistrée dans le fichier est utilisée ; les formules ne sont pas recalculées.

    Puis-je créer du XML imbriqué ?

    Oui. Activez « Imbriquer les en-têtes à points » : une colonne nommée address.city devient <address><city>…</city></address>, et des colonnes numérotées comme phone.0 et phone.1 deviennent des éléments <phone> répétés.
