Confidentialité

Vos fichiers

Les fichiers que vous choisissez et le texte que vous collez sont traités uniquement dans votre navigateur, sur votre appareil. Ils ne sont ni téléversés ni stockés, et ne sont transmis ni à nous ni à qui que ce soit. Les seules requêtes réseau des pages portent sur les propres fichiers du site (pages, styles et scripts). Leur Content Security Policy bloque les requêtes que des scripts pourraient utiliser pour envoyer des données (connect-src 'none'), et cela vaut aussi pour le worker d'arrière-plan qui effectue la conversion.

Pas de cookies, pas de pistage

Ce site ne dépose aucun cookie, n'utilise pas le stockage local et ne contient aucun code de mesure d'audience, de publicité ou de réseaux sociaux. Tous les fichiers du site, y compris la bibliothèque SheetJS, sont servis par ce site lui-même, et non par des serveurs tiers.

Hébergement

Le site est hébergé sur GitHub Pages, un service de GitHub, Inc. Selon la documentation de GitHub, l'adresse IP de chaque visiteur d'un site GitHub Pages est enregistrée et conservée à des fins de sécurité. Nous n'avons pas accès à ces journaux. Les détails figurent dans la déclaration de confidentialité de GitHub (GitHub Privacy Statement).

Qui gère ce site

Klarto Convert est un projet de Arsenii Khmelnytskyi, Bulgarie. Les questions sur ce site peuvent être posées dans le suivi des tickets (issue tracker) du dépôt du code source.
