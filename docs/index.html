Convert XML, JSON, CSV and Excel files in your browser

Ten small tools for everyday data files. Each one runs entirely in your browser, explains its conversion rules and shows exact error messages.

Tools

  • XML to JSONAttributes, namespaces and CDATA included.
  • JSON to XML@keys become attributes, arrays repeated elements.
  • XML to ExcelOne row per record, numbers and dates as real cells.
  • Excel to XMLAny sheet to XML, headers as element names.
  • JSON to CSVNested data in dotted columns, Excel-ready.
  • CSV to JSONAuto delimiter, quoted fields, European CSV.
  • JSON to ExcelJSON types kept, ISO dates as date cells.
  • Excel to JSONRows as objects, dates in ISO 8601.
  • CSV to ExcelKeeps leading zeros and long numbers intact.
  • XML ValidatorChecks well-formedness, shows line and column.

What these tools do differently

  • Your files are not uploaded. The conversion runs in your browser: the pages load only their own files from this website and never send your data anywhere. You can check this in the Network tab of your browser's developer tools.
  • The rules are written on every page: how attributes, arrays, nested objects, numbers and dates are converted, so you know what to expect.
  • Errors name the line and the column, and say how to fix the problem.

Questions and answers

Is it free?

Yes. The tools are free and need no account.

Which browsers work?

Current versions of browsers that support JavaScript modules in Web Workers. We test the pages in Google Chrome.

Are my files stored anywhere?

No. Files are read into the memory of your browser tab and are gone when you close or reload the page. There are no cookies and no analytics.
