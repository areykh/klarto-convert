Convertir Excel a XML

Elija un libro para convertir una de sus hojas en XML: un elemento por fila, un elemento hijo por columna y las fechas en ISO 8601.

Su archivo no sale de su dispositivo: la conversión se realiza en su navegador y no se sube nada.

Opciones

    Cómo se usa

    1. Elija un archivo .xlsx, .xlsm, .xlsb, .xls u .ods, o arrástrelo al recuadro.
    2. Si el libro tiene varias hojas, elija una en la lista «Hoja».
    3. Indique los nombres del elemento raíz y del elemento de fila, y active «Anidar encabezados con puntos» si quiere XML anidado.
    4. Descargue el archivo .xml o copie el resultado.

    Cómo funciona la conversión

    Cómo se lee el libro

    • Formatos: .xlsx, .xlsm, .xlsb, .xls (Excel 97–2003) y .ods (LibreOffice, OpenOffice). Una hoja por conversión; elíjala después de cargar el archivo.
    • Las celdas numéricas siguen siendo números y las de texto, texto: un código postal guardado como texto, como 01067, conserva su cero inicial. VERDADERO y FALSO (TRUE y FALSE) pasan a ser booleanos; las celdas de error dan su código, como #DIV/0!, y las celdas vacías, null (en XML, un elemento vacío).
    • Las celdas con formato de fecha se convierten en texto ISO 8601: 2026-11-20, 2026-11-20T14:30:00 o 14:30:00 para una hora; no se incluye zona horaria. Se admiten los libros con el sistema de fechas 1904.
    • En las fórmulas se usa el resultado guardado en el archivo; no se recalcula nada. Una celda combinada solo tiene su valor en la celda superior izquierda.
    • Las celdas de encabezado vacías reciben el nombre column_N, y los duplicados, _2, _3.

    De la hoja a XML

    • Cada fila bajo el encabezado se convierte en un elemento (predeterminado: <row>) dentro del elemento raíz (predeterminado: <rows>); cada columna se convierte en un elemento hijo con el nombre de su encabezado.
    • Los nombres de encabezado que no son nombres XML válidos se ajustan: los espacios y otros caracteres no válidos se sustituyen por «_». Un encabezado que empieza por «@» se convierte en atributo.
    • Con «Anidar encabezados con puntos» activado, address.city se convierte en <address><city>…</city></address>.

    Preguntas y respuestas

    ¿Qué archivos puedo usar?

    Libros de Excel (.xlsx, .xlsm, .xlsb), archivos antiguos de Excel 97–2003 (.xls) y hojas de cálculo OpenDocument (.ods). Los archivos protegidos con contraseña no se pueden leer: quite antes la contraseña en Excel. Para archivos CSV, use CSV a JSON y después JSON a XML.

    ¿Qué aspecto tiene el XML?

    Cada fila bajo el encabezado se convierte en un elemento <row> dentro de <rows>, y cada celda, en un elemento hijo con el nombre del encabezado de su columna. Puede cambiar el nombre de ambos elementos. Los encabezados que empiezan por «@» se convierten en atributos, y las celdas vacías, en elementos vacíos como <note/>.

    ¿Cómo se convierten las fechas y las fórmulas?

    Las celdas con formato de fecha se convierten en texto ISO 8601, por ejemplo 2026-11-20 o 2026-11-20T14:30:00. En las fórmulas se usa el valor guardado en el archivo; las fórmulas no se recalculan.

    ¿Puedo crear XML anidado?

    Sí. Active «Anidar encabezados con puntos»: una columna llamada address.city se convierte en <address><city>…</city></address>, y columnas numeradas como phone.0 y phone.1 se convierten en elementos <phone> repetidos.
