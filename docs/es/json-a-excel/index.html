Convertir JSON a Excel (XLSX)

Elija un archivo JSON o pegue JSON para obtener un archivo .xlsx con una fila de encabezado. Los números, los booleanos y las cadenas de JSON conservan su tipo en Excel.

Su archivo no sale de su dispositivo: la conversión se realiza en su navegador y no se sube nada.

Opciones

    Cómo se usa

    1. Elija un archivo JSON o JSON Lines, arrástrelo al recuadro o pegue el JSON y pulse Convertir.
    2. Revise «Origen de las filas» y elija otro array si la herramienta eligió uno que no es el correcto.
    3. Decida si las cadenas de fecha ISO deben convertirse en fechas de Excel.
    4. Revise la vista previa y descargue el archivo .xlsx.

    Cómo funciona la conversión

    La regla de los arrays: datos anidados en columnas

    • Los objetos anidados reciben nombres de columna con puntos: customer.name, customer.address.city.
    • Los arrays reciben columnas numeradas a partir de 0: tags.0, tags.1. Los arrays de objetos combinan ambas cosas: items.0.sku, items.0.qty, items.1.sku.
    • Un objeto o un array vacío da una celda vacía bajo su propio nombre de columna.
    • Las columnas aparecen en el orden en que se encuentran por primera vez. Si una fila no tiene un valor, esa celda queda vacía.
    • Las filas salen de un array de nivel superior, si lo hay. Si no, se usa el array de objetos más grande, por ejemplo orders; puede elegir otro en «Origen de las filas». Sin un array así, todo el documento es una fila.

    Cómo se crea el archivo de Excel

    • Se conservan los tipos de JSON: los números pasan a ser celdas numéricas; true y false, celdas booleanas, y las cadenas, celdas de texto, de modo que "01067" sigue siendo texto.
    • Con «Fechas ISO como fechas de Excel» activado, cadenas como 2026-11-20 o 2026-11-20T14:30:00 se convierten en celdas de fecha. Las cadenas con zona horaria (Z o +02:00) siguen siendo texto, porque las celdas de Excel no tienen zona horaria.
    • La primera fila es el encabezado: recibe un Autofiltro, y el ancho de las columnas se calcula a partir de las primeras 200 filas.
    • Una hoja admite como máximo 1.048.576 filas y 16.384 columnas, y una celda, como máximo 32.767 caracteres. Los datos que superan estos límites se rechazan, y el texto más largo se recorta con un aviso.

    Preguntas y respuestas

    ¿Los números siguen siendo números en Excel?

    Sí. Los números JSON pasan a ser celdas numéricas; true y false, celdas booleanas, y las cadenas, celdas de texto, de modo que "01067" conserva su cero inicial.

    ¿Cómo se tratan las fechas?

    Con «Fechas ISO como fechas de Excel» activado, cadenas como 2026-11-20 o 2026-11-20T14:30:00 se convierten en celdas de fecha. Las cadenas con zona horaria, como 2026-11-20T14:30:00Z, siguen siendo texto, porque las celdas de Excel no tienen zona horaria.

    ¿Cómo se distribuyen los objetos y arrays anidados?

    Según la regla de los arrays: los objetos anidados reciben nombres de columna con puntos (customer.city), y los arrays, columnas numeradas (items.0.sku, items.1.sku). Cada elemento de un array recibe sus propias columnas, así que el número de filas sigue siendo el número de registros.

    ¿El archivo de Excel tiene formato?

    Solo un formato mínimo: la fila de encabezado recibe un Autofiltro, y el ancho de las columnas se calcula a partir de las primeras 200 filas. No se definen fuentes, colores ni paneles inmovilizados.
