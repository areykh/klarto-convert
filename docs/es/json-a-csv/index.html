Convertir JSON a CSV

Elija un archivo JSON o pegue JSON para obtener un archivo CSV. Los objetos y arrays anidados se aplanan con una regla fija, descrita más abajo.

Su archivo no sale de su dispositivo: la conversión se realiza en su navegador y no se sube nada.

Opciones

    Cómo se usa

    1. Elija un archivo JSON o JSON Lines, arrástrelo al recuadro o pegue el JSON y pulse Convertir.
    2. Revise «Origen de las filas»: si hay un array de nivel superior, se usa tal cual; si no, el array de objetos más grande. Elija otro si es necesario.
    3. Elija el delimitador y el separador decimal que espera su programa de hojas de cálculo, y mantenga el BOM UTF-8 si abre el archivo en Excel. En esta página vienen preseleccionados el punto y coma y la coma decimal.
    4. Descargue el archivo .csv o copie el resultado.

    Cómo funciona la conversión

    La regla de los arrays: datos anidados en columnas

    • Los objetos anidados reciben nombres de columna con puntos: customer.name, customer.address.city.
    • Los arrays reciben columnas numeradas a partir de 0: tags.0, tags.1. Los arrays de objetos combinan ambas cosas: items.0.sku, items.0.qty, items.1.sku.
    • Un objeto o un array vacío da una celda vacía bajo su propio nombre de columna.
    • Las columnas aparecen en el orden en que se encuentran por primera vez. Si una fila no tiene un valor, esa celda queda vacía.
    • Las filas salen de un array de nivel superior, si lo hay. Si no, se usa el array de objetos más grande, por ejemplo orders; puede elegir otro en «Origen de las filas». Sin un array así, todo el documento es una fila.

    Cómo se escribe el CSV

    • Los campos que contienen el delimitador, una comilla doble o un salto de línea se ponen entre comillas dobles; las comillas interiores se duplican. Las filas terminan con CRLF.
    • Con la coma decimal, los números JSON se escriben como 1,5. Los valores de texto nunca se modifican.
    • La marca de orden de bytes UTF-8 (tres bytes al inicio) hace que Excel abra el archivo como UTF-8, de modo que caracteres como ñ, ü, é o ж se muestran correctamente.

    Preguntas y respuestas

    ¿Cómo se aplanan los objetos y arrays anidados?

    Los objetos anidados reciben nombres de columna con puntos, como customer.city. Los arrays reciben columnas numeradas a partir de 0: tags.0, tags.1, y en los arrays de objetos, items.0.sku, items.1.sku. Un objeto o array vacío da una celda vacía. Las columnas aparecen en el orden en que se encuentran por primera vez.

    ¿Qué delimitador debo elegir para Excel?

    Excel para Windows abre los archivos CSV con el separador de listas de la configuración regional. En EE. UU. y el Reino Unido es la coma; en Alemania, Francia, España y muchos otros países es el punto y coma, con la coma como separador decimal. Elija el delimitador y el separador decimal que correspondan. En esta página vienen preseleccionados el punto y coma y la coma decimal, como los espera Excel con la configuración regional de España.

    ¿Por qué las tildes o la ñ se ven mal en Excel?

    Excel para Windows abre un archivo CSV sin marca de orden de bytes con la codificación heredada del sistema en lugar de UTF-8. Mantenga activada la opción «BOM UTF-8 para Excel»: añade tres bytes al inicio que indican a Excel que el archivo es UTF-8.

    ¿Puedo convertir JSON Lines?

    Sí. Un archivo con un valor JSON por línea (JSON Lines, NDJSON) se lee como una lista, y cada línea se convierte en una fila.

    ¿Son seguros los números muy grandes?

    Los navegadores leen los números JSON como valores de coma flotante de 64 bits, así que los números enteros mayores que 9.007.199.254.740.991 se redondean antes de la conversión. La herramienta avisa cuando encuentra uno. Guarde esos identificadores como cadenas entre comillas en el JSON.
