Privacidad

Sus archivos

Los archivos que elige y el texto que pega se procesan solo en su navegador, en su dispositivo. No se suben, no se guardan y no se envían ni a nosotros ni a nadie más. Las únicas solicitudes de red que hacen las páginas son las de los propios archivos del sitio web (páginas, estilos y scripts). Su política de seguridad de contenido (Content Security Policy) bloquea las solicitudes que los scripts podrían usar para enviar datos (connect-src 'none'), y esto también se aplica al proceso en segundo plano (Web Worker) que realiza la conversión.

Sin cookies ni seguimiento

Este sitio web no instala cookies, no usa el almacenamiento local y no contiene código de analítica, publicidad ni redes sociales. Todos los archivos del sitio web, incluida la biblioteca SheetJS, se sirven desde este mismo sitio web, no desde servidores de terceros.

Alojamiento

El sitio web está alojado en GitHub Pages, un servicio de GitHub, Inc. Según la documentación de GitHub, la dirección IP de cada visitante de un sitio de GitHub Pages se registra y se almacena por motivos de seguridad. No tenemos acceso a esos registros. Encontrará los detalles en la Declaración general de privacidad de GitHub.

Quién gestiona este sitio web

Klarto Convert es un proyecto de Arsenii Khmelnytskyi (Bulgaria). Las preguntas sobre este sitio web pueden plantearse en el gestor de incidencias (issue tracker) del repositorio del código fuente.
