Convertir XML a JSON

Elija un archivo XML o pegue XML para obtener JSON con una correspondencia documentada y reversible. Los errores del XML se muestran con su línea y su columna.

Su archivo no sale de su dispositivo: la conversión se realiza en su navegador y no se sube nada.

Opciones

    Cómo se usa

    1. Elija un archivo XML, arrástrelo al recuadro o pegue el XML en el campo de texto y pulse Convertir.
    2. Revise las opciones: si los elementos repetidos son arrays en todas partes, qué elementos deben ser siempre arrays y la sangría.
    3. Mire la vista previa y descargue el archivo .json o copie el resultado.
    4. Si el XML tiene un error, el mensaje indica la línea y la columna. Corríjalo y vuelva a convertir.

    Cómo funciona la conversión

    Correspondencia entre XML y JSON

    • Cada elemento se convierte en una clave con el nombre del elemento. Los prefijos de espacio de nombres forman parte del nombre: soap:Body.
    • Los atributos se convierten en claves con una «@» delante: id="7" se convierte en "@id": "7". Las declaraciones de espacio de nombres se conservan de la misma forma, como "@xmlns:soap".
    • Un elemento que solo contiene texto se convierte en ese texto. Si además tiene atributos o elementos hijos, su texto va en "#text": <price currency="EUR">12.50</price> se convierte en {"price": {"@currency": "EUR", "#text": "12.50"}}.
    • Los elementos que se repiten bajo el mismo padre se convierten en un array, en el orden del documento. Los nombres intercalados se agrupan, así que no se conserva el orden entre elementos de nombres distintos.
    • Las secciones CDATA se convierten en texto normal. Los comentarios, las instrucciones de procesamiento y el DOCTYPE se descartan. Las entidades definidas solo en una DTD externa, como &nbsp; en XHTML, se conservan tal como están escritas, con una nota.
    • Un elemento vacío como <note/> se convierte en "". Los espacios en blanco entre elementos se descartan, y se quitan los espacios al principio y al final del texto, salvo dentro de xml:space="preserve".
    • Todos los valores siguen siendo cadenas, porque XML no tiene tipos de datos: "00123" conserva sus ceros a la izquierda.

    Preguntas y respuestas

    ¿Cómo se guardan los atributos y el texto en el JSON?

    Cada atributo se convierte en una clave con «@» delante de su nombre, así que id="7" se convierte en "@id": "7". Un elemento que solo contiene texto se convierte en ese texto. Si el elemento también tiene atributos o elementos hijos, el texto se guarda en "#text".

    ¿Por qué todos los números van entre comillas?

    XML no tiene tipos de datos, así que cada valor se convierte como cadena. Convertir "00123" o "1e5" en números cambiaría los datos. Convierta los tipos en su propio código, donde sabe qué campos son números.

    ¿Cuándo se convierte un elemento en array?

    Cuando aparece más de una vez bajo el mismo padre. Con «Elementos repetidos como arrays en todas partes» activado (la opción predeterminada), un elemento que se repite en cualquier punto se convierte en array en la misma ruta de todos los registros, de modo que todos los registros tienen la misma forma. Para elementos que nunca se repiten en este archivo, escriba sus nombres en «Siempre como arrays».

    ¿Qué pasa con los espacios de nombres, los comentarios y CDATA?

    Los prefijos se mantienen en los nombres, como "soap:Body", y las declaraciones de espacio de nombres se conservan como claves "@xmlns", de modo que JSON a XML devuelve los mismos espacios de nombres. Las secciones CDATA se convierten en texto normal. Los comentarios y las instrucciones de procesamiento se descartan.
