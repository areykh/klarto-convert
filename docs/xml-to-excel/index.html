Convert XML to Excel (XLSX)

Choose an XML file or paste XML to get an .xlsx file with one row per record. Nested elements and attributes become columns with dotted names.

Your file stays on your device: the conversion runs in your browser and nothing is uploaded.

    How to use it

    1. Choose an XML file, drop it on the box, or paste XML and press Convert.
    2. Check “Rows from”: the tool picks the largest list of repeated elements, such as every <order>. Choose another list if needed.
    3. Check the preview of the first rows.
    4. Download the .xlsx file and open it in Excel or another spreadsheet program.

    How the conversion works

    XML and JSON mapping

    • Each element becomes a key with the element's name. Namespace prefixes stay part of the name: soap:Body.
    • Attributes become keys with an “@” in front: id="7" becomes "@id": "7". Namespace declarations are kept the same way, as "@xmlns:soap".
    • An element with only text becomes that text. If it also has attributes or child elements, its text goes under "#text": <price currency="EUR">12.50</price> becomes {"price": {"@currency": "EUR", "#text": "12.50"}}.
    • Elements that repeat under the same parent become an array, in document order. Interleaved names are grouped, so the order between different names is not kept.
    • CDATA sections become ordinary text. Comments, processing instructions and the DOCTYPE are dropped. Entities defined only in an external DTD, such as &nbsp; in XHTML, are kept as written, with a note.
    • An empty element such as <note/> becomes "". Whitespace between elements is dropped and text is trimmed, except inside xml:space="preserve".
    • All values stay strings, because XML has no data types: "00123" keeps its leading zeros.

    The array rule: nested data in columns

    • Nested objects get dotted column names: customer.name, customer.address.city.
    • Arrays get numbered columns starting at 0: tags.0, tags.1. Arrays of objects combine both: items.0.sku, items.0.qty, items.1.sku.
    • An empty object or array gives an empty cell under its own column name.
    • Columns appear in the order they are first found. A value that a row does not have stays empty.
    • Rows come from a top-level array if there is one. Otherwise the largest array of objects is used, for example orders; you can choose another one under “Rows from”. Without such an array, the whole document is one row.

    How the Excel file is written

    • With “Detect numbers and dates” on, values such as 24.90 become numbers and ISO dates such as 2026-11-20 or 2026-11-20 14:30 become date cells. Other date formats, such as 20.11.2026, stay text.
    • Values with leading zeros, a leading plus sign or more than 15 digits stay text, because Excel would drop the zeros or round the digits.
    • The first row is the header: it gets an AutoFilter, and column widths follow the first 200 rows. There is no other formatting.
    • A sheet holds at most 1,048,576 rows and 16,384 columns; a cell holds at most 32,767 characters. Larger data is refused, and longer text is cut with a warning.

    Questions and answers

    Which elements become rows?

    The largest list of repeated elements that contain data of their own, for example each <order> inside <orders>. You can choose another list, or the whole document as a single row, under “Rows from” after the first conversion.

    How are nested elements and attributes turned into columns?

    Column names follow the path with dots: customer.name, item.0.@sku, item.1.@sku. Attributes start with “@”; the text of an element that also has attributes is in a column ending in #text. An element that repeats in one record gets numbered columns in every record.

    Are numbers and dates real Excel values?

    With “Detect numbers and dates” on, 24.90 becomes a number and 2026-11-20 becomes a date cell. Values with leading zeros such as 01067, a leading plus sign or more than 15 digits stay text, so they are not changed.

    How large can the XML file be?

    We tested a 20 MB XML file with 102,973 records: it gave a 12 MB .xlsx file in 5.5 to 7.5 seconds (Node.js on a 4-core laptop). Large files need much more memory than their size. An Excel sheet holds at most 1,048,576 rows and 16,384 columns.
