Privacy

Your files

Files that you choose and text that you paste are processed only in your browser, on your device. They are not uploaded, not stored and not sent to us or to anyone else. The only network requests the pages make are for the website's own files (pages, styles and scripts). Their Content Security Policy blocks requests that scripts could use to send data (connect-src 'none'), and this also applies to the background worker that does the conversion.

No cookies, no tracking

This website sets no cookies, uses no local storage, and contains no analytics, advertising or social media code. All files of the website, including the SheetJS library, are served from this website itself, not from third-party servers.

Hosting

The website is hosted on GitHub Pages, a service of GitHub, Inc. According to GitHub's documentation, the IP address of every visitor of a GitHub Pages site is logged and stored for security purposes. We have no access to these logs. Details are in the GitHub Privacy Statement.

Who runs this website

Klarto Convert is a project by Arsenii Khmelnytskyi, Bulgaria. Questions about this website can be asked in the issue tracker of the source code repository.
