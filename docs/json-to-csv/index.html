    How to use it

    1. Choose a JSON or JSON Lines file, drop it on the box, or paste JSON and press Convert.
    2. Check “Rows from”: a top-level array is used as is, otherwise the largest array of objects. Choose another one if needed.
    3. Choose the delimiter and decimal separator that your spreadsheet program expects, and keep the UTF-8 BOM if you open the file in Excel.
    4. Download the .csv file or copy the result.

    How the conversion works

    The array rule: nested data in columns

    • Nested objects get dotted column names: customer.name, customer.address.city.
    • Arrays get numbered columns starting at 0: tags.0, tags.1. Arrays of objects combine both: items.0.sku, items.0.qty, items.1.sku.
    • An empty object or array gives an empty cell under its own column name.
    • Columns appear in the order they are first found. A value that a row does not have stays empty.
    • Rows come from a top-level array if there is one. Otherwise the largest array of objects is used, for example orders; you can choose another one under “Rows from”. Without such an array, the whole document is one row.

    How CSV is written

    • Fields that contain the delimiter, a double quote or a line break are put in double quotes; quotes inside are doubled. Rows end with CRLF.
    • With the decimal comma, JSON numbers are written as 1,5. Text values are never changed.
    • The UTF-8 byte order mark (three bytes at the start) makes Excel open the file as UTF-8, so characters such as ü, é or ж display correctly.

    Questions and answers

    How are nested objects and arrays flattened?

    Nested objects get dotted column names, such as customer.city. Arrays get numbered columns starting at 0: tags.0, tags.1, and for arrays of objects items.0.sku, items.1.sku. An empty object or array gives an empty cell. Columns appear in the order in which they are first found.

    Which delimiter should I choose for Excel?

    Excel on Windows opens CSV files with the list separator of the region settings. In the US and the UK that is a comma; in Germany, France, Spain and many other countries it is a semicolon, with a comma as the decimal separator. Choose the delimiter and decimal separator to match.

    Why do umlauts or accents look wrong in Excel?

    Excel on Windows opens a CSV file without a byte order mark in the system's legacy encoding instead of UTF-8. Keep the option “UTF-8 BOM for Excel” on: it adds three bytes at the start that tell Excel the file is UTF-8.

    Can I convert JSON Lines?

    Yes. A file with one JSON value per line (JSON Lines, NDJSON) is read as a list, and every line becomes a row.

    Are very large numbers safe?

    Browsers read JSON numbers as 64-bit floating-point values, so whole numbers above 9,007,199,254,740,991 are rounded before conversion. The tool warns when it finds one. Keep such IDs as strings in quotes in the JSON.
