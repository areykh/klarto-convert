Convert Excel to XML

Choose a workbook to turn one of its sheets into XML: one element per row, one child element per column, with dates in ISO 8601.

Your file stays on your device: the conversion runs in your browser and nothing is uploaded.

    How to use it

    1. Choose an .xlsx, .xlsm, .xlsb, .xls or .ods file, or drop it on the box.
    2. If the workbook has several sheets, choose one in the “Sheet” list.
    3. Set the names of the root and row elements, and turn on “Nest dotted headers” if you want nested XML.
    4. Download the .xml file or copy the result.

    How the conversion works

    How the workbook is read

    • Formats: .xlsx, .xlsm, .xlsb, .xls (Excel 97–2003) and .ods (LibreOffice, OpenOffice). One sheet per conversion; choose it after loading.
    • Number cells stay numbers, text cells stay text: a postcode stored as text, such as 01067, keeps its leading zero. TRUE and FALSE become booleans, error cells their code such as #DIV/0!, empty cells null (in XML an empty element).
    • Cells formatted as dates become ISO 8601 text: 2026-11-20, 2026-11-20T14:30:00, or 14:30:00 for a time; no time zone is added. Workbooks with the 1904 date system are handled.
    • For formulas, the result saved in the file is used; nothing is recalculated. A merged cell has its value only in its top-left cell.
    • Empty header cells are named column_N, duplicates get _2, _3.

    From the sheet to XML

    • Each row below the header becomes an element (default <row>) inside the root element (default <rows>); each column becomes a child element named after its header.
    • Header names that are not valid XML names are adjusted: spaces and other invalid characters become “_”. A header that starts with “@” becomes an attribute.
    • With “Nest dotted headers” on, address.city becomes <address><city>…</city></address>.

    Questions and answers

    Which files can I use?

    Excel workbooks (.xlsx, .xlsm, .xlsb), old Excel 97–2003 files (.xls) and OpenDocument spreadsheets (.ods). Password-protected files cannot be read: remove the password in Excel first. For CSV files, use CSV to JSON and then JSON to XML.

    What does the XML look like?

    Each row below the header becomes a <row> element inside <rows>, and each cell becomes a child element named after its column header. You can rename both elements. Headers that start with “@” become attributes, and empty cells become empty elements such as <note/>.

    How are dates and formulas converted?

    Cells formatted as dates become ISO 8601 text, for example 2026-11-20 or 2026-11-20T14:30:00. For formulas, the value saved in the file is used; formulas are not recalculated.

    Can I create nested XML?

    Yes. Turn on “Nest dotted headers”: a column named address.city becomes <address><city>…</city></address>, and numbered columns such as phone.0 and phone.1 become repeated <phone> elements.
